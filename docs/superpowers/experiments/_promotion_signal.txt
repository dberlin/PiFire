signal, AND a demand that one statistic clear a threshold. Every threshold offered is a

row of Appendix A. Two error counts are kept:
  wrong  = accepted when unjustified, or refused when justified (as in SECTION 2)

inspection. The generic plant's own coast at the probe's reference is 0.1 C against MAK's
25.1 C, so 'shorter coast' there is a comparison between two roundings; MAK is also the
grill that actually overshot. A count that let 0.4 C of generic noise outvote 25 C of MAK
would be measuring the wrong plant.
